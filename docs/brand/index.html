  • 外发光opacity 0.18 ↔ 0.55
  • 光标主体scale 0.985 ↔ 1.000 + opacity 0.68 ↔ 1.00
  • N 字符scale 1.000 ↔ 1.004 (微)
  • 无障碍prefers-reduced-motion 时停止
