# Nexterm 全应用基础视觉重设计

- 日期：2026-07-22
- 状态：已批准

## 目标

在不改变五区布局、多工作区保活、面板开关、拖拽宽度和 IPC/Pinia 边界的前提下，将界面重构为深色优先的“连续工作舱”。深浅主题、Naive UI、终端和模块外壳统一消费一套语义 token。

## 视觉方向

- 深色主体验使用石墨外壳、冷色表面和电光青主强调；紫罗兰只作为次级类型色。
- 成功、警告、危险分别使用酸性绿、琥珀和珊瑚红，不用于普通装饰。
- 常驻区域依靠色阶与 1px 分隔线组织，不使用浮卡阴影。
- 圆角只保留 3px、4px、6px、8px；8px 仅用于菜单、抽屉、命令面板和通知等浮层。
- UI 保持 12-13px 主字号、28px 常规控件/列表行和 4px 间距基准。

## 布局尺寸

- TitleBar：40px。
- Activity rail：44px。
- LeftSidebar：默认 272px，范围 216-420px。
- TabBar：34px。
- Explorer：默认 288px，范围 220-440px。
- StatusBar：24px。

## 边界

- 不新增后端命令或业务状态。
- Monaco 内容主题继续尊重用户选择；只统一编辑器外壳。
- 终端 ANSI 色、选区与光标跟随应用主题。
- 设置、欢迎页、命令面板、上下文菜单、通知及核心模块全部纳入视觉基线。
